# Plan B: Demonstrationsdaten und Generalisierung

Alternativer Projektentwurf: Eine bestehende Policy wird mit gezielt variierten Demonstrationen trainiert oder feinabgestimmt und auf getrennten Aufgabenvariationen geprüft.

Der [Überblick mit Literatur](OVERVIEW_AND_LITERATURE.md) beschreibt Forschungsfrage, mögliche Simulationsaufgaben und Abnahmekriterien. Der Ordner enthält einen Entwurf; daraus folgt kein durchgeführtes Experiment.

Die tatsächlich implementierten Versuche sind im [Experimentindex](../../experiments/README.md) zu finden.
