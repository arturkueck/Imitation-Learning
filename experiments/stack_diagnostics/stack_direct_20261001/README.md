# Direct-Chunk-Regressor gegen Diffusion

Vergleich eines deterministischen Action-Chunk-Predictors mit der Diffusionspolicy auf denselben State-Eingaben; untersucht Übergangsreaktion und Closed-Loop-Verhalten.

## Einstieg

- [ERGEBNISSE.md](ERGEBNISSE.md): Kontrollen, Befunde und Grenzen.
- [config.json](config.json): Direct-Konfiguration.
- [diffusion_config.json](diffusion_config.json): Diffusions-Konfiguration.
- [paired_boundary_comparisons.json](paired_boundary_comparisons.json): Gepaarte Übergangsprüfung.
