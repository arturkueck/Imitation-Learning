# Diagnose zu schwacher Transportaktionen

Untersuchung der Zielkonditionierung und höhenabhängigen Transportreaktion einer eingefrorenen State-Diffusion-Policy.

## Einstieg

- [DIAGNOSE.md](DIAGNOSE.md): Erklärung, Gegenproben und Grenzen.
- [verification.json](verification.json): Dokumentierte Prüfung.
- [transport_distribution.png](transport_distribution.png): Darstellung der Transportverteilung.

## Einordnung

Eingabe-Gegenproben und ein diagnostischer XY-Regler sind keine neu trainierte Policy und kein kausaler Nachweis einer einzelnen Fehlerursache.
