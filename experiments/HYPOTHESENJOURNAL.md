# Hypothesenjournal

Historischer Erstimport am 19.11.2026 aus Git und den im Repository verfügbaren
Versuchsberichten. Er erfasst die wesentlichen Entscheidungspunkte der
Stapelversuche sowie ausgewählte Baseline- und Vision-Befunde. Die
[Themenübersicht](README.md) führt zu weiteren Versuchen.

## Verwendung

- Eine Zeile pro relevantem Ereignis, neue Zeilen unten ergänzen. Dieselbe
  Hypothesen-ID bei Planung, Messung, Entscheidung und Korrektur wiederverwenden.
  Für eine neue Frage eine freie ID vergeben. Bei Arbeit ohne Hypothese steht
  ein Gedankenstrich. Für eine Übergabe von unten nach Thema oder ID suchen.
- Bei neuen Einträgen Datum und Uhrzeit in Europe/Berlin angeben. Im
  historischen Import steht bei fehlender Ereigniszeit das dokumentierte
  Datum, der Versuchszeitraum oder ausdrücklich das Datum der Git-Erfassung.
  Die Hypothesenspalte fasst die Forschungsfrage der Quelle zusammen.
  Bei Diagnosen sind die Prüfbedingungen im Bericht verlinkt.
- **Gestützt**, **nicht gestützt** und **uneindeutig** beziehen sich auf den
  jeweiligen Vergleich. **Diagnose**, **technisch bestanden**, **technisch
  gestoppt**, **geplant**, **pausiert** und **dokumentiert** kennzeichnen
  andere Ereignisse. Modell-/Szenenpaare mit geteilten Starts und Parents
  sind abhängige Wiederholungen.
- Relative Links führen zu Berichten dieses Checkouts. Beim separaten Branch
  `experiment_three_cube_critic` steht der jeweilige Beleg als `Commit:Pfad`.
  Git kann ihn mit `git --no-optional-locks show <Commit>:<Pfad>` direkt lesen.
  Die Einträge geben den Stand der verlinkten Quellen wieder.
