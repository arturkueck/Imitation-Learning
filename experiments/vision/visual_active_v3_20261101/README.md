# Vision V3: Ansichten und Aufnahmebedarf

Wahrnehmungsmodell für wechselnde Handkameraansichten, Datenverträge für Aufnahmevorschläge und begrenzte Folgeuntersuchungen.

## Einstieg

- [PLAN.md](PLAN.md): Fragestellung und ursprüngliches Design.
- [DATA_CONTRACT.md](DATA_CONTRACT.md): Datenrollen und Aufnahmevertrag.
- [RUN_STATUS.md](RUN_STATUS.md): Historischer Start- und Monitoringkontext.
- [FOLLOWUP.md](FOLLOWUP.md): Folgeuntersuchung.
- [completion_gate.py](completion_gate.py): Technische Abschlussprüfung.

## Einordnung

PLAN.md und RUN_STATUS.md beschreiben datierte Stände. Konkrete Laufartefakte separat prüfen; ein fallender Head-Loss belegt keinen Nutzen aktiver Blickwahl.
